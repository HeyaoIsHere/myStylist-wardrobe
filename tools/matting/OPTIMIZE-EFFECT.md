> 记录人：本地优化任务 · 2026-09-20
> 任务范围：仅修改 `tools/matting/service.py`（跳过检测/抠图效果的任何状态都会被观察）。

## 1. 从哪下手优化 —— 先定位三个根因

最初的症状是三个，从浏览器 overlay 上肉眼可见：

| 症状 | 用户描述 | 根因（读 service.py 定位） |
|---|---|---|
| 绿色覆盖面积过大、不沿衣物边缘 | 「绿色 matting 覆盖面积太大，没能沿着 edge 抠像」 | `complete_mask_with_key()` 无条件执行，chroma-key 阈值太松（`t=25`、合并 `ratio>0.3`），把「与背景颜色不同」的无关色块一并并进 mask |
| 边缘方形 / 锯齿 | 「edge 都是方形锯齿状态」 | `binary_closing()`（最多 12 次扩张迭代）把轮廓向外扩、角变方；且 alpha 是 0/255 硬二值，没有任何半透明过渡 |
| （隐含）结果不稳定 | 「怎么固定模型表现，让每次启动都保持高精度」 | 无随机种子控制；SAM2 默认可能是 float16；cuDNN benchmark 模式造成运行间不确定性 |

这三个根因对应三处处置：**收紧补全门槛**、**砍掉形态学扩张 + 换软边 alpha**、**锁死确定性**。

## 2. 改动前后对照

### 2.1 chroma-key 补全：从「无条件 + 宽松」改为「救援态 + 严格」

**Before：** `cut_out()` 得到 SAM2 掩膜后，无条件跑 `complete_mask_with_key()`（`t=25`、`ratio>0.3`）
——意思是「只要像素颜色跟背景差 25，且占格子 30% 就并进去」，背景里每件东西都可能被吸进 mask。

**After：**

1. 先做健康度检查 `touches_all_borders()` + `mask_looks_like_background()`（SAM2 没找到衣物、选中了整背景时直接判失败）；
2. 只有当 `cover < 0.35`（掩膜只盖住检测框 35% 以下，说明 SAM2 漏得太多）才进入救援：
   `complete_mask_with_key()` 改为 **严格参数** `t=35`、`ratio>0.5`，只收敛「几乎肯定是衣物」的色块；
3. chroma-key 救援只会在救援 gate 后面触发，健康掩膜永远不会被它改坏。

### 2.2 形态学扩张：直接移除

**Before：** `binary_closing()` 最多 12 次 `binary_erosion/dilation` 迭代。作用是把 mask 内部小洞补上，
代价是把 silhouette 向外扩一圈、把曲线角磨成方角，社交媒体上常见的「方块状」抠图正是它 + 硬二值 alpha 一起造成的。

**After：** 移除 closing。mask 的健康度交给 `pick_garment_mask()` 里已有的分数加权，
空洞交给 feathered alpha 在视觉上自然过渡，不再用几何扩张。

### 2.3 边缘：硬二值 → 高斯羽化的软 alpha

**Before：** `overlay[..., 3] = mask * 255`（0/255 硬二值），边缘是楼梯状锯齿。

**After：** 新增 `feather_mask(bin_mask, sigma=1.0)`——对一个已落成 0/255 的二进制轮廓，
用 `scipy.ndimage.gaussian_filter` 先模糊再 clip 回 [0,1]，得到 1–2px 的半透明过渡带，
轮廓方向真实（aspect-correct），只在原轮廓的位置做羽化，不拉伸、不变形：

```python
def feather_mask(bin_mask, sigma: float = 1.0):
    if bin_mask.dtype != np.float32:
        bin_mask = bin_mask.astype(np.float32)
    return np.clip(ndimage.gaussian_filter(bin_mask, sigma=sigma), 0.0, 1.0)
```

`cut_out()` 的产出从硬二进制 mask 变为浮点 alpha（`np.float32` 0..1），
渲染路由同步改了 alpha 通道的写入方式，语义一致（float alpha = 半透明度）。

> 为什么不用「把 SAM2 的 256×256 logits 直接 bilinear 放大」来做软边？
> 256×256 是方形的，用它非等比拉伸到照片长宽比会让圆形变椭圆、轮廓失真；
> 而先二值再在当前分辨率下羽化，保证边缘像素落在真实的轮廓坐标上。

### 2.4 确定性：种子 + fp32 + 关闭 benchmark

**Before：** 无种子；cuDNN benchmark 自动挑算法（每次启动可能不同）；SAM2 默认可能走 float16 路径。

**After：**

```python
torch.manual_seed(7)
if cuda:
    torch.backends.cudnn.deterministic = True
    torch.backends.cudnn.benchmark = False
    torch.cuda.manual_seed_all(7)
```

SAM2 建模时捕获 `model.set_use_float16` 并强制 `False`（fp32），
DINO 本就 fp32。三个 DL 阶段（detect/box、SAM2 mask、救援）全部 fp32 + 固定 seed。

## 3. 增加的新方法清单

- `pick_garment_mask()` 现在 `enumerate(masks, scores)` 并用 `best_idx` 返回三元组 `(best_mask, best_cover, best_idx)`——确定性地选出置信度最高的掩膜，而不是只有一份。
- `feather_mask()`：高斯羽化软 alpha（见 2.3）。
- `touches_all_borders()` + `mask_looks_like_background()`：健康度守卫，判断 SAM2 是否「选了整个背景」。
- `complete_mask_with_key()` 参数收紧为 `t=35` / `ratio>0.5`，且只在 `cover < 0.35` 救援态触发。
- `load_models()` 确定性锁（种子 / deterministic / benchmark off / fp32）。

## 6. 局限性 & 后续可优化方向

- 本优化范围是「裁得干净 + 边缘软 + 固定」，**没有**动 DINO 的 prompt/阈值策略（accessory 等 fallback 保持原样）；
  SAM2 检测完全失败时仍走 chroma-key 救援或全透明，这属于能力边界，不是本次目标。
- 更高精度的路径（后续如需）：SAM2 细化为多粒度 prompt、DINO box 做 NMS/阈值调优、
  或在救援态给 mask 加形态学「只闭小孔不扩张」的受限版本。
- determinism 目前是 seed/flag 级（cuDNN deterministic 并非 100% bit-exact 保证）；
  若想彻底位级可复现，需要并到 fp32 + 固定输入尺寸，代价是更慢。

## 7. 第二轮：深色地板平铺实拍 + 褶皱（2026-09-20 续）

### 7.1 现象（用户两张真实照片，地板平铺、有褶皱阴影）

- 绿色 matting 保留了背景里的一部分地板（周围大片绿）；
- 服装本身因褶皱/凸起/阴影没有被绿色完全覆盖——「衣物周围是绿但衣物本身不绿」。

### 7.2 从哪下手 —— 先跑离线诊断（不猜）

写 `_diag2.py`（直接驱动 service.py 里的同款模型，不经过 HTTP）对两张照片逐候选打点：

| 照片 | DINO box | 候选（mean RGB / cover / floor 族占比） | 旧 picker 选 |
|---|---|---|---|
| test1（暗胡桃地板 + 小浅色连衣裙） | 69% 画框高 | cand0 = 裙子本体（[189,179,171] / cover .038 / floor 0.2%）<br>cand1 = 整幅（96%，地板+衣物）<br>cand2 = 地板板坯+影（77%，floor 51.5%） | **cand2**（板坯！） |
| test2（亮木地板 + 深色裙 + 褶皱高光） | 大框 | cand0 = 高光碎点（0.4%）<br>cand1/cand2 = 裙+影大块（floor 40%/27.6%） | **cand1**（含 40% 地板） |

结论是**两个症状同一个根**：SAM2 的三个候选里混有"地板板坯"（floor slab），而旧
`pick_garment_mask` 只看"覆盖 DINO 框比例"——板坯覆盖比例最大，所以每次都被选中。
小裙子本体反而因 `cover < 0.15` 被当作"sleeves-only 碎片"直接淘汰。褶皱阴影在板坯
掩膜里进一步雕刻出洞/湾（凹口连通到外界，`binary_fill_holes` 填不了），于是"周围绿、衣不绿"。

### 7.3 加了什么办法（全部在 service.py）

1. **背景家族判据 `border_family_mask()`**：把"这是背景自己家族的像素"算成一把布尔掩膜：
   - 与画框边缘中位色接近（raw 距离 < 28），或
   - 与边缘色同色相但更暗（`cos > 0.985` 且亮度 < 0.95）——**地板的阴影区**也归地板家族。
   （衣服通常比其身周地板阴影更亮，所以衣服不会被误吞。）
2. **picker 征收"地板税"**：候选评分 `score -= 5.0 × (mask 中地板族像素占比)`。
   板坯直接出局，真衣服获胜。白底电商图里所有候选都是白色系，地板族占比同高同低，只减常数、排序不变，不回退。
3. **小物体准入**：`cover < cover_lo` 的候选若满足 `接触边界 ≤1 边`、`frac ≥ 1%` 且
   `地板族 < 8%`（紧凑的、无背景的物体），不再当碎片淘汰——"大框里的小裙子"由此被选回。
4. **救援门禁**：cover<0.35 才触发的 chroma-key 救援，先自检 keying 结果（把地板当
   钥匙色时自检盘大部分属于地板族 → 丢弃救援、保留小裙子原件）。
5. **褶皱填充 `complete_garment_folds()`**：只填**凹形褶皱湾**：
   - 1/4 分辨率上 r=3 圆盘闭运算（等价全分辨率 12px，成本约 0.3s）——闭运算只填窄凹口，
     外轮廓与细带子**精确不变**（圆盘闭运算的固有性质，方锯齿不会回来）；
   - 填充再用"服装自身色线"闸门（`cos > 0.994`，从掩膜核心里排除地板族后取中位色）：同
     色相更亮/更暗都吸（褶皱高光/阴影），裤腿间露出的地板楔形（异色相）不被吸；
   - `fill_holes` 提前跑（先填室内封闭褶皱），闭运算桥接出的新口袋不再被无差别整块填满。

### 7.4 实测对比（两次运行，字节级一致 ✓）

| 指标 | test1 旧 → 新 | test2 旧 → 新 |
|---|---|---|
| 选中的候选 | 地板板坯 cand2 → **裙子本体 cand0** | 含 40% 地板 cand1 → 含 27.6% cand2 |
| alpha 覆盖 | 77.3% → **3.2%**（只剩裙子） | 64.7% → 68.9% |
| alpha 地板族占比 | 51.5%（raw） → **0.1%** | 40% → 27.6% |
| 剩余洞（px） | 41 | 291 |
| 两次运行 alpha 字节一致 | ✓ | ✓ |

数字说明：test1 两个症状（地板大片绿 + 衣不绿）当场消掉；test2 由 picker 修复了大部分，
但新选中的掩膜仍含约 27.6% 地板族像素——**如果浏览器里看仍有残留地板**，那是 SAM2 把
裙影和地板接成了同一块，下一轮应从「掩膜级细修」（对赢家做地板族减法 + 保持连通域）入手，
而非继续调 picker。

## 8. 第三轮：白底图长方形覆盖 / 白衣服白底识别不出 / 地板残留（2026-09-22）

### 8.1 现状测量（53 张真实照片批量体检）

写 `_batch_diag.py` 对用户目录全部 53 张（此前 20 张 + 新加的 top5~16、shoe4~10、
accessory5~9、bag4~5、bottom5~8 等）跑完整管线并打点：

- **manual fallback（"Auto cut couldn't finish"）**：2/53（top8、top13）；
- **白底图掩膜含背景族像素**：40/53 超标，其中 13 张 ≥99% —— 全为白底电商图；
- 白色背景图里 SAM2 的赢家常是"含纸面的大片"，`rect_like` 0.64~0.89，即用户看到的
  "整个长方形/正方形覆盖、没找到 edge"；
- 地板照片 test2 掩膜仍含 27.6% 地板族像素（上一轮已预告）。

三类症状共因：**统一背景（白纸/地板）时 SAM2 会顺带把背景并入掩膜；而白衣服在白底上
对模型是"无色差"，候选里根本没有干净的衣服掩膜可挑**。

### 8.2 加了什么办法

1. **zoom 回放尺寸 bug**：0.25x 粗网格在无法整除尺寸时多一行，闭运算结果与原图 shape
   不齐（`ValueError` 会传染成管线错误）——回放改为按实际 shape 的精确 factor。
2. **`refine_mask()` 掩膜级细修**：剥掉赢家里的背景族像素得到"衣服本体" → 1/4 分辨率
   16px 圆盘闭运算把被白缝/褶皱断开的部分重新连上 → 用原掩膜 6px 膨胀做帽，永不超过
   原掩膜包络。**本体 <20% 时放弃减法**（那说明衣服本身就是背景色——白衣服白底，减了
   等于删衣服，交给下面第 3 条）。
3. **低对比重试通道（lane 2）**：主通道失败、或赢家 >60% 是背景族颜色（"白化掩膜"）时，
   对原图做**非锐化提边**（亮度维 `img + 2.2×(img − gaussian_σ12)`，纯几何、确定性），
   在增强图上重跑 DINO 检测 + SAM2 + 全套链；掩膜坐标与增强图 1:1，直接映射回原图。
   增强后白衣服的边缘线可见，SAM2 有东西可分割。护卫：L2 结果若小于主掩膜的 30%
   （可能只是边缘线残片）则丢弃、保留主掩膜。

### 8.3 实测对比（53 张批量）

| 指标 | 改前 | 改后 |
|---|---|---|
| manual fallback | 2 | 2（同 top8/top13，纯白衣服纯白底） |
| 地板 test1 地板族残留 | 51.5% → 0.1%（上轮） | **0.0%** ✓ |
| 地板 test2 地板族残留 | 27.6% | **16%** ✓ |
| 白底彩色衣服（top4/top6/dress1/bag3/bottom4/5/shoe3…） | 0.00–0.07 ✓（本轮未回退） | 同左 ✓ |
| 白/浅色衣服白底（21 张） | 板坯/长方形、rect 0.64–0.89 | 走 lane 2 增强分割，结构回归衣服轮廓；但颜色统计无法再证明好坏（白衣服=背景色，见下） |

**必须如实说明的边界**：白衣服白底时，"掩膜里多少像素是背景色"这个统计指标**永远≈100%**，
因为衣服就是背景色——数字测不出来，只能肉眼验收。本轮对这些照片的改进是：用增强图
让 SAM2 有真实边缘可分割（不再整片覆盖），结构上从"板坯"回归"衣服轮廓"；代价是：如果
增强图上无边缘可循（纯白衣服、纯白纸、无褶皱），仍会退回 manual（top8/top13 就是），
这是物理局限，需要人工橡皮兜底或换背景重拍。**请你在浏览器里重点验证这 21 张白衣服。**

## 9. 第四轮：shoe 抠不全回归 / 边缘锯齿 / 高光点不被覆盖（2026-09-22 续）

### 9.1 症状与诊断路径

- **shoe2 不能完整抠像**：逐候选打点发现真鞋是框内 cand1 的 277k 整块；上一轮的
  albino→L2 把它换成了增强图上 166k 的残缺掩膜（`_shoe_diag2.py` 证明 cand0 的
  3 个小块全是框外杂屑，`inside_box=0`）。一度误判为"成对结构"，加了 shoes 成对
  先验反而选中杂屑——已**回滚该先验**并实测验证。
- **边缘锯齿粗大**：根因是 SAM2 输出的是 256×256 低分辨率**二值**掩膜，轮廓天然
  是 4px 方块——1px 羽化盖不住。治本：改用**浮点 logits 上采样**。
- **高光点不绿**：皮革/缎面镜面高光是"脱饱和亮白"，不在服装色线上（cos≈0.93<
  0.994）被褶皱闸门挡掉；白底白物场景连色模型都建不起来（sel<300 提前退出）。

### 9.2 改动（全部 service.py）

1. **软边从二值掩膜改为 logits**：新增 `logits_alpha()` —— 赢家的 256×256 原始
   logits → sigmoid → bilinear 上采样到原图分辨率（与 SAM2 自身映射一致的矩形
   映射，aspect 不失真）→ 乘 3px 膨胀帽（软边不越界）→ 掩膜内 α 垫底 0.85 →
   σ0.8 羽化 → **再垫底 keep×0.8**。最后一次垫底是踩坑补的：σ1.0 羽化会把
   1–3px 宽的丝巾带/鞋带抹到可见阈值以下（accessory3 因此出现 11 万 px 假洞），
   垫底后细条存活。
2. **褶皱/高光闸门扩展**：吸收判据 = `cos>0.994` 或 `脱饱和且亮于服装中位 1.10×`
   （镜面高光）或（白洗模式）`暗于纸面 1.02× 的灰色阴影`。白洗模式（整幅 ≥92%
   背景族）下色模型改用掩膜原始核心——白衣服白底也能吸收灰色褶皱阴影。
3. **口袋封口后填内**：闭运算桥接封口的新封闭口袋，内部按吸收判据逐像素填
   （93k px 的 bridging-pocket 残留因此解决）；再把 alpha 阶段 3px 帽会封口的
   **窄口湾**在二进制阶段镜像预填（实测这些湾 98% 像素通过吸收判据）。
4. **albino→L2 通道按类别收紧**：只对 tops/dresses/outerwear/bottoms 触发
   （大件服装才会与纸面熔成板坯）；鞋/包/首饰等小件保留原始通道掩膜——shoe2
   的残缺正是 L2 替换造成的，收紧后不再发生。
5. **shoes 尺寸闸门**：以 accessories 同级放宽（frac_lo 0.003、准入 0.004）。
